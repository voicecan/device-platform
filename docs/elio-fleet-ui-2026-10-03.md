# Elio 多设备管理调整（2026-10-03）

设备入口改为多设备列表，每页 25 台。搜索名称或序列号、连接状态及授权用户组筛选均由服务器执行；翻页采用游标，不在浏览器一次性加载全部设备。点击设备进入对应详情，保留录音、连接诊断、固件及原有控制功能。

连接设备不再作为独立主菜单。设备页的“添加设备”打开原生弹窗，继续使用既有蓝牙 → Wi-Fi 两步流程，自动备份与服务器设置保持原逻辑，确认服务器上线后进入该设备详情。旧连接链接和回调入口继续兼容。后台操作进行时禁止关闭弹窗，避免用户误中断；空闲时支持关闭、Escape 与焦点返回。

新增 GET /api/v1/admin/devices 为带权限范围的分页列表接口，包含总数及同一筛选范围内的在线/离线数量。既有 GET /api/v1/devices 的数组响应保持不变。过滤条件及用户身份变化使旧游标失效。

保留暖白背景、白色面板和青绿色操作色。列表在窄屏转换为设备卡片。详情与列表分别管理浏览位置，返回列表保留搜索条件和页码。

验证：类型检查通过；全套测试 183 项，其中 182 通过、1 跳过、0 失败；固定协议运行库校验通过。真实浏览器验证搜索、筛选、设备详情、返回列表、弹窗关闭/焦点以及 320/390/768/1024/1440 宽度。示例列表只用于布局检查，没有写入设备数据。

本次没有重新配网或改设备固件。分页布局与查询并不代表已验证一万台设备并发连接，连接容量、负载与稳定性需独立压测。
